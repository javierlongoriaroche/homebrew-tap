# javierlongoriaroche/tap

Homebrew formulae by javierlongoriaroche.

## TermTube

[TermTube](https://javierlongoriaroche.github.io/termtube/) is a lightweight YouTube Music client for the terminal (~50 MB of RAM).

```bash
brew install javierlongoriaroche/tap/termtube
termtube
```

This also installs `mpv` and `yt-dlp`. On first launch TermTube finds your YouTube Music session in your browser or opens music.youtube.com so you can sign in.
